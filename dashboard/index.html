PREFERENCES & SYSTEM

ตั้งค่า

ปรับแต่งการทำงานของระบบ · ไม่แสดงว่าสำเร็จหากยังไม่ได้บันทึก

◉Wi-Fiตั้งค่าบน ESP ผ่าน provisioning

การตั้งค่า Wi-Fi ทำบน ESP8266 ตามระบบ firmware ปัจจุบัน · Dashboard ไม่ส่งรหัสผ่าน Wi-Fi

⌁MQTTปรับ credentials และสถานะ broker

ตั้งค่าและทดสอบการเชื่อมต่อ MQTT ได้ที่หน้าการเชื่อมต่อ

◉ระบบน้ำRelay, AUTO/MANUAL และตาราง ESP

Relay และตารางควบคุมโดย firmware · ไม่มีการย้าย safety logic มาไว้ใน Dashboard

➤Telegramยังไม่ได้เชื่อมต่อ

ยังไม่มี Telegram integration ใน repository นี้ · ไม่มีการแสดงสถานะหรือปุ่มจำลอง

♧การแจ้งเตือนยังไม่มี notification service

ยังไม่ได้ตั้งค่าบริการแจ้งเตือนภายนอก

▣ระบบเวอร์ชัน, cache และการตรวจสอบ
Firmware baselineยังไม่มีข้อมูลDashboard versionยังไม่มีข้อมูลCache versionlungna-shell-v4

⌂ข้อมูลการเงินในเครื่องข้อมูลเดิมจาก Dashboard เก็บ local-only

รายการบัญชีเดิมยังอยู่ใน localStorage ของเบราว์เซอร์นี้ และเปิด/ส่งออกได้จากหน้า “ข้อมูล”

ข้อมูลผู้ดูแลระบบ

ไม่มี backend authentication หรือการจัดการผู้ใช้ในเวอร์ชันนี้ · ไม่อ้างว่ามีการยืนยันตัวตน
